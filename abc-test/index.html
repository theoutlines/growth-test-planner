A/B/C test: how much longer than an A/B test?

About 1.8 times as long for the same change. Each version gets a third of the traffic instead of half, and comparing B and C with A means two comparisons, so each one needs a slightly wider margin to stay at 95% confidence.

What A/B and A/B/C catch

The same paywall: 50,000 people a week (about 214,000 in 30 days), 2.75% paying, weekly $6.99 and annual $39.99 sold half and half. The smallest change each version must make to be caught:

With three versions, each of B and C is compared with A, with the margin split between the two comparisons (Bonferroni). The planner reads A/B/C results the same way.

When a third version is worth it

  1. Both B and C are bold. On the paywall above, each version has to move revenue by about +12% to show up in 4 weeks. Two small tweaks won’t.
  2. You would ship either one. If you only care about one of them, test that one against A and get the answer sooner.
  3. Don’t compare B with C. The test is sized for each one against A. If B and C both win, pick on the range, not on which number is higher.
  4. Short on traffic? Run A/B first, then test the next idea against the winner.
